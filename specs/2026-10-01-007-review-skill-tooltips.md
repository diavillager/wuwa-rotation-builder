# 검수 화면의 Encore 스킬 툴팁

## 목적과 기준

PRD 13·14절 및 체크리스트 6절의 사람 검수를 돕기 위해 Encore 원본의 스킬 설명을 읽기 전용으로 제공한다. 현재 character-data-pipeline 브랜치에서 기존 검수 화면을 보완한다.

## 범위와 사용자 동작

- 검토 페이지 오른쪽 맨 아래에 `스킬 툴팁` 필드를 둔다. 선택된 공명자가 바뀌면 설명도 바뀐다.
- 기본 공격, 공명 스킬, 공명 해방, 공명 회로, 변주 스킬, 반주 스킬 순서로 분류·실제 스킬명을 표시하고 펼쳐 설명을 읽는다.
- Encore `Skills[].SkillDescribe`만 사용한다. 별도 대미지 정보표인 `SkillAttributes`·성장 수치·소모 재료·영상은 표시하지 않는다. 설명 본문에 포함된 수치와 효과는 보존한다.
- 원본의 명시적 분류·ID를 사용하며, 아이콘 카드와 임의로 연결하거나 편집 중인 카드의 분류로 설명을 추론하지 않는다. 자동 배정 여부와 무관하게 읽을 수 있다.

## 데이터와 구현

검수 `ReviewSource`에 선택적인 설명 목록을 추가한다. 원본 HTML은 실행하지 않고 줄바꿈과 글자를 보존한 일반 텍스트로 변환하여 React 텍스트로 렌더링한다. 새 백업·Export의 복원 자료에 설명을 포함하고 Import 시 형태를 검증한다. 기존 파일에 설명이 없어도 불러오기를 허용하며 설명 없음으로 표시한다.

## 비범위

Rotation/Character 앱 DB 구조 변경, Skill 자동 의미 확정, 설명 편집, 대미지 표, 외부 HTML 실행, 게임 설명의 재작성 및 전체 재수집.

## 예외와 테스트

원본·설명이 없으면 해당 분류의 설명이 없음을 표시하고 다른 검수 작업을 막지 않는다. 요청하지 않은 고유 스킬·조화도 파괴는 제외한다. HTML 줄바꿈·엔티티·실행 요소 제거, 지정 6개 분류 필터, 표 제외, 화면 최하단 배치 및 대상 전환, 백업 복원과 이전 파일 호환성을 검증한다. lint/test/build 및 검수 build를 실행한다.

## 미확정 사항

없음. 기존 수집 원본을 사용하며 새 수집에도 같은 추출 규칙을 적용한다.
