# 공명자 무기군 수집 및 검수

## 목적과 관련 요구사항

PRD 13·14절의 검수 데이터 전달 경로에 공명자 무기군을 포함한다. 사용자가 승인한 다섯 종류(대검·직검·권총·권갑·증폭기)를 Encore의 명시적 WeaponType 값으로 수집한다. 앱 DB 갱신은 사용자가 이후 전달할 JSON을 에이전트가 재검증한 다음 수행한다.

## 범위와 UX

- 공명자 수집 초안에 무기군을 담고 검수 기본 정보의 속성 다음에 무기군 선택을 제공한다.
- 소스의 무기군을 초기값으로 사용하고 사용자가 수정할 수 있다. 없는 값은 미지정으로 표시하며 추론하지 않는다.
- 검수 자동 저장·백업·Import·Export 및 앱 데이터 검증·catalog에 무기군을 보존한다.
- 기존 브라우저 검수/구버전 JSON에 무기군 필드가 없으면 동일 공명자 ID의 로컬 수집 Encore 원문에서 보충한다. 기존 수동 지정값과 명시적인 미지정은 덮어쓰지 않는다. 다른 검수값·카드 순서·선택·이미지·기준 hash는 유지한다.
- 앱 catalog에 무기군이 있으면 파티 카드에 `속성 / 무기군`을 표시한다. 없으면 기존처럼 속성만 표시한다.

## 비범위

현재 앱 DB의 자동 변경, 신규 공명자 등록, 전체 재수집·검수 초기화, Rotation 및 Skill 의미 변경은 하지 않는다.

## 도메인과 구현

공용 무기군 타입 및 명시적 ID 대응은 1=대검, 2=직검, 3=권총, 4=권갑, 5=증폭기다. 목록의 ID/한국어 이름과 상세의 ID를 검증한다. 알 수 없는 ID와 이름 불일치는 오류로 처리한다. 앱 Character JSON은 optional `weaponType` 한국어 문자열을 사용해 기존 schemaVersion 1과 호환한다. ReviewState는 미지정 `null`과 구버전의 필드 부재를 구분한다.

기존 파일은 무기군이 없어도 계속 읽는다. 잘못된 무기군 값은 Import/검증에서 거부한다. 스냅샷의 기본 정보와 검수 상태를 함께 내보내며 최종 앱 데이터는 에이전트 재검증 경로를 유지한다.

## 예외와 테스트

다섯 ID 매핑, 미지원 값·목록 이름 충돌, 구버전 필드 부재, 수동 지정/미지정 보존, 브라우저 저장 복원 시 누락 보충, 백업/Export 왕복 및 앱 catalog/파티 표시를 확인한다. lint/test/build와 검수 앱 build를 실행한다.

## 남은 사항

무기군이 없는 과거 자료는 호환성을 위해 허용한다. 이번 작업 완료 후 사용자가 전달하는 검수 JSON을 기준으로 앱 DB를 갱신한다.
