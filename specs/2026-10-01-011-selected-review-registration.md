# 선택한 공명자와 스킬의 앱 반영

## 목적 및 관련 요구사항

PRD 13·14절과 사용자 확정 규칙에 따라 검수 백업에서 초상화를 선택한 공명자와 등록한 스킬만 앱에 반영한다. 미검수 후보가 남아 있다는 이유로 선택 완료된 항목의 반영을 막지 않는다.

## 범위와 UX

- 초상화가 없는 공명자는 반영 대상에서 제외한다.
- 선택한 초상화가 있는 공명자는 등록된 스킬만 노출한다. 미검수·미등록 후보는 추가하지 않는다. 백업 원본과 브라우저 검수 값은 변경하지 않는다.
- 파티 편성 선택창은 지정한 초상화를 128×160px로 표시하고, 고정 너비 카드 안에서 이름을 초상화 아래에 배치한다. 파티 슬롯은 초상화·번호·이름·슬롯 안내를 확대하되 좌측 정렬과 오른쪽 여백을 유지한다. 사이클 필드는 왼쪽의 넓은 영역, 공명자 스킬 진열 필드는 오른쪽에 배치한다. 스킬 진열 카드는 정사각형에 가까운 형태로 64px 아이콘 아래에 분류명·실제 스킬명을 표시한다. 긴 스킬명은 두 줄까지 표시하고 전체 이름은 툴팁으로 보존한다. 드래그 안내 문구는 제거한다. 드래그 시 전체 카드 복제본을 잡은 위치에 맞춰 표시한다. 사이클의 연결 스킬은 아이콘과 분류를 표시하고 실제 이름은 툴팁으로 보존한다. 분류가 없는 기존 스킬은 실제 이름을 사용한다.
- 웹의 전체 검수 검증·Export 규칙은 유지한다. 이번 기능은 전달받은 백업을 에이전트가 재검증해서 앱 DB에 반영하는 경로다.

## 구현 및 도메인 영향

### 초상화 라인 및 드래그 표시 보완

- 사이클의 고정 공명자 열은 128px 정사각형 초상화로 표시하고 각 라인의 높이도 128px로 맞춘다. 이름은 버튼의 접근성 이름과 툴팁으로 제공하고 이미지가 없는 슬롯은 placeholder로 표시한다. 기존 번호·활성 강조·고정 스크롤·파티 재정렬을 유지한다.
- 오른쪽 스킬 진열 높이는 개막·반복 사이클 전체 높이에 맞추고 목록만 내부 스크롤한다. `개막 · 공명자` 안내 문구를 제거한다.
- 빈 입력, 스킬이 든 입력, 진열 스킬, 입력 내부 스킬의 드래그는 실제 카드 복제본을 커서 위치에 그려 표시한다. 브라우저의 이미지 포함 drag snapshot에 의존하지 않는다. 복제본은 hit test와 접근성 트리에서 제외하며 drop·dragend·blur·숨김·unmount에서 제거한다.
- 활성 라인과 입력 위치 규칙은 변경하지 않는다. 한 스킬만 든 입력은 기존처럼 전체 입력을 이동하고 여러 스킬 중 하나는 내부 재정렬한다. 소유권·스크롤·도메인 연산을 유지한다.
- 카드 종류별 이미지/텍스트 복제와 위치 추적·종료 정리를 테스트하고 실제 화면에서 정사각형·동일 높이·스크롤을 확인한다.

검수 저장소에 선택 항목 준비 연산을 추가한다. 필수 이미지의 디코딩·hash, 등록 스킬·자동 행동 참조와 기존 DB hash를 확인한다. 기존 공개 Skill ID는 보존한다. 기존 미검수 스킬은 비노출로 유지하며 신규 미검수 후보는 생성하지 않는다. Rotation 데이터·stage·suppression·Timeline은 변경하지 않는다.

## 비범위

자동 승인 웹 API, 검수 값 추론, 미선택 공명자 삭제, 원본 백업 변경, 배포.

## 예외와 테스트 계획

초상화 없음 제외, 등록 스킬만 포함, 후보 미검수 상태 유지, 자동 행동이 미등록 스킬을 참조하면 실패, DB hash 충돌 실패를 테스트한다. 실제 3명의 이미지와 데이터를 검증하고 characters:validate, lint, test, build를 실행한다.
