# 방랑자 공유 스킬 보완과 검수 목록 탭

## 목적 및 관련 요구사항

PRD 13·14절과 검수 JSON·브라우저 저장 보완을 따른다. 사용자 승인에 따라 회절 여성 방랑자 1502의 누락된 Encore 스킬 정보를 회절 남성 방랑자 1501의 공유 데이터로 보완한다. 전체 공명자 검수 목록을 복원하고 속성 탐색을 개선한다.

## 범위와 UX

- 1502의 Encore Skills가 비었을 때만 1501을 보완 원본으로 사용한다. 양측 SkillId·SkillTreeGroupId가 1501이며 속성이 같은지 확인한다. ID·이름·초상화는 1502를 유지한다.
- 원본 두 응답을 보존하고 스킬 후보 출처·검수 화면·백업에 보완 원본 1501을 명시한다. 자동 배정은 기존처럼 명시 분류·이름·정확한 아이콘 경로에 근거한다. 최종 사람 검수는 유지한다.
- 좌측 순서는 공명자 목록 → 자동 매핑 및 정렬 → 검증 및 파일 관리다.
- 공명자 목록 위에 응결·용융·전도·기류·회절·인멸을 가로 버튼으로 표시한다. 선택 속성의 목록만 보이며 초기 필터는 응결이다. 필터 변경 자체는 현재 검수 내용을 바꾸지 않는다.
- 이번 사용자가 요청한 데이터 초기화는 기존 JSON Import 규칙을 이용해 전체 수집 목록의 미검수 초기값으로 교체한다. 이후 JSON Import는 계속 파일의 전체 목록으로 교체한다. 앱 Rotation DB는 초기화하지 않는다.

## 구현 및 데이터 영향

공유 스킬 해결을 순수 함수로 분리한다. 수집 시 1501 응답을 별도 보존하고 검수 로드 시 동일한 검사로 해석한다. 검수 snapshot에는 보완 출처를 저장한다. 브라우저 자동 저장은 초기화된 전체 목록을 보존한다. Rotation 도메인에는 변화가 없다.

## 비범위

다른 공명자 간 임의 복사, 다른 속성의 방랑자 자동 매핑, 자동 등록 승인, 앱 DB 변경, 일반적인 데이터 초기화 UI 신설.

## 예외 및 테스트

원본 Skills가 있으면 보완하지 않는다. donor ID·그룹·속성 불일치, 빈 donor, 네트워크 오류는 오류로 남긴다. 여성 ID·초상화 보존, 출처 및 툴팁 보존, 속성 순서·초기 응결·탭 필터·검수 내용 유지, 64개 초기 목록 복원을 검증한다. lint/test/build를 실행한다.

## 미확정 사항

없음. 다른 속성 방랑자의 동일 처리 확대는 이번 범위에 포함하지 않는다.

## 검증 결과

- 전체 64개 ID의 미검수 초기 백업을 생성하고 실제 Import 검증을 통과했다. 브라우저 목록 교체 및 자동 저장을 확인했다.
- 1502는 초상화 포함 14개 이미지가 정상 수집됐다. 1501 원본의 12개 스킬 레코드에서 자동 대응 8개, 대상 6분류의 툴팁 8개를 복구했다. 공명 해방·공명 회로에는 서로 다른 원본 ID/설명이 같은 아이콘에 대응하므로 기존 정책대로 자동 의미 선택을 하지 않고 안내한다.
- 테스트 248개와 앱·검수 도구 build, lint, format 검사를 통과했다. 검수 build의 기존 Vite config loader 호환성 안내는 유지된다.
