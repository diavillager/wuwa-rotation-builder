# 검수 타수·JSON Import와 자동 행동 연결 보완

## 목적 및 기준

사용자가 요청한 여섯 항목을 기존 검수 도구에 반영한다. PRD 13·14절, 체크리스트 6절, 검수 JSON 전달 spec을 기준으로 같은 character-data-pipeline 브랜치에서 작업한다.

## 범위 및 UX

- 기본 공격·공명 스킬·공명 해방·공명 회로 카드에 0~10 타수 메타데이터를 제공한다. 각 카드에 단일 값을 지정한다. 0은 타수 미지정이며 타수별 카드를 자동 생성하지 않는다.
- 별도 분류순 정렬은 현재 미등록을 뒤로 모으고 분류→타수 오름차순→현재 순서로 정렬한다.
- 검수 JSON Export 파일을 Import해 페이지 메모리의 검수 내용을 복원한다. 현재 지정 목록에 관계없이 파일의 목록으로 통째로 교체하고 파일에 없는 공명자는 화면에서 제거한다. 현재 미저장 편집이 있으면 교체를 확인한다. 웹에서 DB나 검수 이력을 저장하지 않는 경계는 유지한다.
- 자동 행동 선택창을 수동 편집 가능하게 한다. 자동 배정은 Encore의 명시적 대응을 사용하고 이미 유효하게 지정한 자동 행동을 분류 편집만으로 비우지 않는다. 같은 기본 공격 분류가 여러 개여도 명시적으로 지정한 스킬 ID를 허용한다.
- 아이콘 동일성 판단은 사용자가 검수한다. 사용자가 루파 중복 보고를 철회했으므로 자동 병합·삭제를 추가하지 않는다.
- 별도 `검수 백업` 버튼은 미완성 공명자를 포함한 전체 목록·검수 값·카드 순서·자동 행동 참조·후보 및 이미지를 한 파일로 저장한다. 기존 JSON Export는 검증 통과 대상만 담는 정책을 유지한다.

## 데이터와 구현

타수는 Character/검수 Skill 메타데이터이며 Rotation의 사용자 stage와 분리한다. 기존 값 누락은 0으로 해석한다. 공개 Skill ID와 기존 Rotation을 재생성하지 않는다.

Import는 버전·공명자 ID·후보 및 카드 순서·명시적 처리 여부·자동 행동 참조·원본/현재 DB 기준·자산 hash/WebP를 검증한다. 전체 검증 성공 후 메모리를 갱신하고 실패하면 현재 편집을 보존한다. 파일에서 임의 경로를 쓰거나 URL을 실행하지 않는다.

## 비범위

Rotation JSON Import/Export, 웹 DB 반영, 임의 자동 의미 승인, 전체 공명자 재수집 및 배포.

## 예외와 테스트

0/10 경계·음수/소수/11 거부, 타수 미지원 분류, 분류/타수/미등록 정렬, 자동 배정 해제 시 직접 수정 보존, 기본 공격 다중 후보와 수동 연결, JSON round trip·손상/중복/다른 대상/참조/이미지 오류·원자적 실패를 시험한다. 실제 원본으로 청초·모니에의 자동 연결을 확인한다. lint/test/build를 실행한다.

## 확정 사항과 호환성

- 새 Export와 백업은 v2이며 복원용 원본 후보·현재 DB snapshot·모든 검증된 후보 이미지를 포함한다. Import는 디스크를 쓰지 않고 페이지 및 서버 메모리에서만 자료를 사용한다. 새로고침 후 자동 복원할 이력을 생성하지 않는다.
- 기존 v1 Export는 파일에 전체 수집 후보가 없으므로 로컬 수집 원본이 남아 있을 때 복원한다. 없거나 검증할 수 없으면 원인을 표시하고 기존 화면을 유지한다.
- Import 시 자동 배정 해제용 임시 이력은 초기화하고 저장된 검수 값과 순서는 그대로 불러온다. 자동 배정 자체가 켜졌다는 상태는 저장하지 않는다.
- JSON Import 최대 크기는 60MB다. 브라우저에서 파일을 읽고 서버는 형식·자산·참조를 검증한다. 여러 대상 중 하나라도 오류면 전체 교체를 하지 않는다.
- 자동 행동은 기본 공격→일반 교체 공격, 변주 스킬→변주, 반주 스킬→반주 관계를 유지하며 해당 분류 내 여러 스킬 중 하나를 직접 지정할 수 있다. Encore 자동 배정은 유효한 기존 지정을 우선 보존하고, 빈 매핑에는 Encore의 명시적 동일 아이콘 대응을 우선 사용한다. 일반 필드 편집 시 연결을 재계산하지 않는다.
- 사용자가 자동 배정 뒤 타수를 직접 지정하면 그 타수에 필요한 분류도 해제 시 보존한다. 타수 미지원 분류로 직접 바꾸면 타수는 초기화한다.

## 실제 데이터 확인

청초의 Encore 기본 공격은 `현으로 이은 검`, 모니에는 `기저 상태 조정`이다. 초기 검수 상태에서는 두 자동 연결이 성공했다. 기존 코드가 분류 편집 때마다 재계산하고 같은 분류가 복수이면 null로 비우는 문제를 제거한다. 원본 파일명으로 매핑하지 않는다.

6명의 실제 수집 자료와 이미지 106개를 포함한 백업을 원본 폴더가 없는 임시 작업 공간에서 복원했다. 후보·타수·자동 행동과 이미지가 복원되고 디스크 파일을 쓰지 않는 것을 확인했다. 검수 화면에서도 해당 백업을 Import하여 6명 목록·타수·자동 행동이 복원되는 것을 확인했다. 브라우저의 다운로드 완료 대기는 도구 시간 초과로 확인하지 못했으며 파일 생성과 복원 경로는 API·저장소 테스트로 검증한다.
