# 공명자 등록 선택과 초상화 기본값

## 목적과 관련 요구사항

PRD 14절의 검수·JSON 전달 및 요구사항 체크리스트의 선택 반영 규칙을 사용자 결정에 맞춰 보완한다. 초상화 선택과 DB 등록 의사를 분리한다.

## 범위와 UX

- 공명자 정보의 두 번째 행에서 등록 여부를 초상화 드롭다운 왼쪽에 배치한다.
- 블록 내부에 등록·미등록 체크박스를 각각 절반 너비, 좌측 정렬로 배치한다. 스킬 등록 선택에도 같은 정렬을 적용한다.
- 두 선택지는 상호 배타적이며 선택을 해제하면 미선택이다. 신규·기존 검수 모두 새 필드의 기본값은 미선택이다.
- 공명자 정보 우측 상단에는 등록 또는 미등록만 표시하고 미선택은 배지를 표시하지 않는다.
- 첫 번째 다운로드 검증된 초상화를 기본 선택한다. 유효 후보가 없으면 미지정이다. 기존 수동 초상화 선택은 보존한다.

## 데이터와 주요 구현

- ReviewState에 registration(pending/include/exclude)을 추가한다. 구버전 필드 누락은 pending으로 복원하고, 기존 검수 내용은 유지한다.
- 구버전 Export는 원본과의 일치 검증을 먼저 수행한 다음 새 기본값을 적용한다.
- 백업·Import·브라우저 복원은 모든 등록 상태를 보존한다. JSON Export와 에이전트 DB 반영은 include만 대상으로 하며 이미지·스킬·참조 검증은 유지한다.
- 미선택·미등록은 DB 반영 대상 제외이며 기존 DB 삭제를 뜻하지 않는다.

## 비범위

이번 작업에서 앱 DB를 갱신하지 않는다. 사용자가 새 JSON을 전달한 후 별도 재검증하여 반영한다. Rotation 도메인·자동 스킬 배정 규칙은 변경하지 않는다.

## 예외와 테스트

- 누락·잘못된 등록 값, 유효 초상화 없음, 구버전 파일 및 브라우저 저장값 복원.
- 초상화가 있어도 미선택·미등록이면 반영 제외, 등록인데 필수 자료가 없으면 오류.
- 체크박스 상호 배타성·해제·배지·순서, 백업/Export 왕복 보존.
- lint/test/build 및 검수 앱 build를 실행한다.

## 미확정 사항

없음. 기존 DB 갱신은 사용자 JSON 전달을 기다린다.

## 검증 결과

- lint 통과, 전체 316개 테스트 통과, 앱 build 및 검수 앱 build 통과.
- 브라우저에서 등록 여부의 왼쪽 배치·미선택 기본값·첫 초상화 자동 선택을 확인했다.
- 기존 ProjectWorkspace 테스트의 React act 경고와 Vite 차기 native config 안내는 남아 있으나 실행은 성공했다.
