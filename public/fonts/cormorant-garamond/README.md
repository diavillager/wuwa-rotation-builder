# Cormorant Garamond 숫자 폰트

파티 편성 번호에 Cormorant Garamond Light(300)를 사용한다. Google Fonts가 제공하는 숫자 `0123456789` subset을 내려받아 앱과 함께 제공하며 런타임에 외부 폰트 서버로 요청하지 않는다.

- 제작자: Christian Thalmann / The Cormorant Project Authors
- 라이선스: SIL Open Font License 1.1, [동봉 원문](OFL.txt)
- 원본: https://github.com/CatharsisFonts/Cormorant
- Google Fonts 메타데이터: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- 다운로드 CSS: https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@300&text=0123456789&display=swap
- 수집일: 2026-10-02

폰트와 함께 저작권 고지 및 OFL.txt를 배포한다. 명조 게임의 원본 폰트라는 의미는 아니다.
